# 李昕彤个人主页与数字分身 V7｜精修验收版

这一版在 V6 的现代产品官网视觉方向上，继续优化移动端导航、键盘焦点、项目详情展开/收起，以及数字分身的常见问题覆盖。

## 本版精修
- 手机屏幕下精简导航，保留项目实践与数字分身入口；GitHub 仍可从首页按钮和快速入口访问。
- 为链接、按钮、输入框和可键盘操作的项目卡片添加清晰焦点状态。
- 项目卡片支持再次点击收起详情，`aria-expanded` 状态同步。
- 数字分身对话区增加辅助阅读语义，并补充项目经历、个人优势、不足与职业方向等常见问题。
- 弹窗支持按 Escape 关闭。
- 保留低饱和自然配色、响应式布局、减少动态效果设置与本地预设问答。

## 本地预览
1. 解压 ZIP。
2. 双击 `index.html`，用 Chrome 或 Edge 打开。
3. 在手机宽度窗口检查导航、项目卡片和数字分身区域。

## 发布前请确认
- 所有项目描述、奖项、时间和功能都与实际经历一致。
- 你是否愿意公开任何联系方式或简历文件（当前未直接公开手机号/邮箱）。
- 数字分身当前是前端预设知识库，不是在线大模型。

## GitHub Pages 发布
建议在 `Eternity1022` 账户下新建公开仓库 `personal-digital-twin`，将 `index.html` 放在仓库根目录，再到 `Settings → Pages` 选择从 `main` 分支的 `/(root)` 发布。发布完成后以 GitHub Pages 实际显示的地址为准；尚未发布前，`https://Eternity1022.github.io/personal-digital-twin/` 只是格式示例。
